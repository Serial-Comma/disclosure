23	**"Buying Time in Singapore":** money buys **time**, time buys **advantage**, accumulated advantage constitutes and reproduces **class**. 35	## 2. What the quantitative exhibit measures
36	
37	> How much time does a family car buy back for a secondary-school child, per day, per year, and across a four-year school career — relative to public transport?
38	
39	Operationalised as: for 100 randomly drawn (HDB estate → public secondary school) pairs, compute door-to-door travel time by **car** and by **public transport**, in both directions:
40	
41	- **AM leg:** must **arrive** at school by **07:30**. Output = required departure time from home.
42	- **PM leg:** **departs** school at **16:00**. Output = arrival time back home.
43	
44	Derived metrics: per-trip advantage, per-day advantage, wake-up-time gap, cumulative hours over 190 school days/year × 4 years.

115	## 5. Technical decisions and rationale
116	
117	### 5.1 Identifying HDB blocks — **decided: two-rule filter**
118	
119	The dump has no HDB flag. Three approaches were tried:
120	
121	| Approach | Result | Verdict |
122	|---|---|---|
123	| `BUILDING` starts with `HDB-` | 5,201 blocks, town label embedded (`HDB-ANG MO KIO`) | Clean but **misses new towns** — Sengkang 28, Punggol 65, because BTO blocks carry project names (`COMPASSVALE HAVEN`) |
124	| Absorb any block within 1.2 km of an `HDB-` seed | 78,745 blocks | **Rejected** — pulled in private condos and landed housing (Bukit Timah 3,808; Central Area 4,258) |
125	| `HDB-` prefix **+** curated new-town road-name rules | **7,200 blocks, all 25 towns** | **Adopted** |
126	
127	Adopted rule:
128	```python
129	def is_blk(r):  # numeric block number, optional letter suffix
130	    return re.match(r'^\d{1,4}[A-Z]?$', (r['BLK_NO'] or '').strip()) is not None
131	
132	# rule 1: explicit HDB tag, town label = BUILDING[4:]
133	if r['BUILDING'].startswith('HDB-') and is_blk(r): keep(town=r['BUILDING'][4:])
134	
135	# rule 2: new-town road families (streets that are overwhelmingly HDB)
136	NEWTOWN = {
137	 'ANCHORVALE':'SENGKANG','COMPASSVALE':'SENGKANG','RIVERVALE':'SENGKANG',
138	 'FERNVALE':'SENGKANG','SENGKANG':'SENGKANG',
139	 'PUNGGOL':'PUNGGOL','EDGEDALE':'PUNGGOL','EDGEFIELD':'PUNGGOL','SUMANG':'PUNGGOL',
140	 'NORTHSHORE':'PUNGGOL','MATILDA':'PUNGGOL','WATERWAY':'PUNGGOL',
141	 'TENGAH':'TENGAH','PLANTATION':'TENGAH','CANBERRA':'SEMBAWANG'}
142	# excluded from rule 2 if BUILDING matches CONDO or NONRES keyword lists
143	CONDO  = ['RESIDENCE','CONDO','SUITES','EXECUTIVE','PARC ','THE ','RIVERTREES',
144	          'HIGH PARK','WATERWOODS','TREASURE','JEWEL','ECOPOLITAN','WATERBANK','PRIVE']
145	NONRES = ['CAR PARK','SHELTER','MARKET','HAWKER','COMMUNITY','SCHOOL','CHURCH','MOSQUE',
146	          'TEMPLE','POLYCLINIC','SUBSTATION','MRT','LRT','STATION','CLUB','SPORT',
147	          'STADIUM','LIBRARY','POLICE','FIRE','CHILDCARE','KINDERGARTEN','MALL',
148	          'PLAZA','POINT','WATERPOINT']

156	### 5.2 Estate construction — **decided: spatial k-means, area-normalised**
157	
158	"Group collections of blocks together" → cluster blocks into estate-sized units. Cluster count is driven by **land area, not block count**, so estate density is uniform in space and immune to the counting bias above.
159	
160	```python
161	latkm = (lat.max()-lat.min()) * 111.32
162	lonkm = (lon.max()-lon.min()) * 111.32 * cos(radians(1.35))
163	area  = max(latkm*lonkm, 0.6)
164	k     = int(max(1, min(10, round(area/1.6))))     # ~1 estate per 1.6 km²
165	KMeans(n_clusters=k, n_init=10, random_state=42)
166	```
167	Estate name = `"{Town} – {most common ROAD_NAME in cluster}"`. Centroid = mean lat/lon of member blocks (a rough proxy for population weighting within the estate).
168	
169	Output: 144 clusters → **142 estates** after dropping two keyword-bleed artifacts (see §8).
170	
171	### 5.3 Sampling — **decided: uniform over both lists, seed 2026**
172	
173	```python
174	random.seed(2026)
175	pairs = [(random.choice(estates), random.choice(schools)) for _ in range(100)]
176	```
177	Uniform, not population-weighted, because (a) the brief said "100 random pairs from the list" and (b) block counts are unreliable. Fully reproducible.
178	
179	**Consequence to state aloud in the viva:** random pairing yields a mean straight-line distance of **11.52 km**, far longer than real school commutes (students mostly attend nearby schools). The distance-banded results (§6.2) are the honest read; the `<5 km` band is the conservative floor.
180	
181	### 5.4 Travel-time model — **decided: analytic distance-decay, calibrated to LTA**
182	
183	Used because live routing is blocked (§7). Not a routing engine; a transparent, auditable approximation.
184	
185	```python
186	CAR_DETOUR, PT_DETOUR = 1.30, 1.45       # network distance / straight line
187	PARK_WALK             = 5.0              # min: walk to car + park + walk into school
188	
189	def v_car(d, peak=True):                 # km/h, rises with trip length (expressway use)
190	    v = 22 + 20*(1 - exp(-d/7.0))        # d=2 → 27.6 ; d=10 → 37.1 ; d=20 → 40.8
191	    return v if peak else v*1.12
192	
193	def v_pt(d):                             # km/h, effective line-haul incl. dwell
194	    return 16 + 22*(1 - exp(-d/9.0))     # d=3 → 22.9 ; d=8 → 30.2 ; d=15 → 33.4
195	
196	def car_time(d, peak=True):
197	    return PARK_WALK + (CAR_DETOUR*d)/v_car(d, peak)*60
198	
199	def pt_time(d, peak=True):
200	    if d < 2.5:                                        # single bus, no transfer
201	        return 6 + (6 if peak else 8) + (PT_DETOUR*d)/18.0*60 + 4
202	    transfers = 1 if d < 11 else 2
203	    wait      = 5 if peak else 6
204	    return (6                                          # access walk
205	            + wait                                     # initial wait
206	            + (PT_DETOUR*d)/v_pt(d)*60                 # in-vehicle
207	            + transfers*(5 if peak else 6)             # transfer penalty
208	            + 5)                                       # egress walk
209	```
210	AM = peak, PM (16:00) = off-peak.
211	
212	**Validation:** a realistic 4 km school trip returns **34.6 min** by PT against LTA's observed **30–35 min**. Good agreement at the distance where most real trips sit.

284	### 9.1 Auth and limits
285	- Token supplied by the user; **JWT, 3-day expiry** (the current one expires ~20 Sep 2026, `exp: 1789899532`). Re-mint at `https://www.onemap.gov.sg/apidocs/register`.

288	- Token-free endpoints (basemaps, static map) are irrelevant here; Search, Routing, Reverse Geocode all need the token.
289	
290	### 9.2 Routing endpoint
291	```
292	GET https://www.onemap.gov.sg/api/public/routingsvc/route
293	```
294	
295	| Param | Notes |
296	|---|---|
297	| `start` | `"lat,lon"` |
298	| `end` | `"lat,lon"` |
299	| `routeType` | `drive` \| `pt` \| `walk` \| `cycle` |
300	| `date` | **`MM-DD-YYYY`** (pt only) |
301	| `time` | `HH:MM:SS` (pt only) |
302	| `mode` | `TRANSIT` \| `BUS` \| `RAIL` (pt only) |
303	| `maxWalkDistance` | metres, e.g. `1200` (pt only) |
304	| `numItineraries` | e.g. `1` (pt only) |
305	
306	Response extraction:
307	- **drive:** `route_summary.total_time` (seconds), `route_summary.total_distance` (metres)
308	- **pt:** `plan.itineraries[0]` → `duration`, `walkTime`, `waitingTime`, `transitTime` (all seconds), `transfers` (int)
309	
310	**Two critical quirks:**
311	1. **`pt` is depart-at only.** The 07:30 arrival must be solved by iteration: seed a departure guess, route it, set the next guess to the returned duration, repeat until `|error| ≤ 2 min`. Two or three iterations converge.
312	2. **`drive` returns free-flow times with no congestion model**, while `pt` uses real timetables. Comparing them raw is **rigged in the car's favour**. Current correction: `×1.35` AM peak, `×1.15` PM, plus a 5-min park-and-walk penalty. This multiplier is a placeholder and is the single weakest link in the whole analysis — see §10 item 2.

23	  error, re-route. Two iterations converge to within a couple of minutes.

44	def call(session, token, start, end, route_type, when=None, tries=3):
45	    """One OneMap routing call. Returns parsed JSON or None."""
46	    params = {

84	def pt_minutes(js):

86	    if not js:

88	    its = (js.get("plan") or {}).get("itineraries") or []
89	    if not its:
90	        return None, None, None, None

92	    return (round(it.get("duration", 0) / 60.0, 1),
93	            round(it.get("walkTime", 0) / 60.0, 1),
94	            round(it.get("waitingTime", 0) / 60.0, 1),
95	            it.get("transfers"))

98	def pt_arrive_by(session, token, start, end, target_dt, seed_minutes=55.0):
99	    """Iterate a depart-at query until the arrival lands on target_dt."""
100	    guess = seed_minutes
101	    best = (None, None, None, None, None)
102	    for _ in range(3):
103	        depart = target_dt - timedelta(minutes=guess)
104	        js = call(session, token, start, end, "pt", when=depart)
105	        total, walk, wait, tr = pt_minutes(js)
106	        if total is None:
107	            return best
108	        best = (total, walk, wait, tr, depart)
109	        err = total - guess
110	        if abs(err) <= 2.0:
111	            break
112	        guess = total
113	    return best
